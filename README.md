# Projeto de Gestão de FIIs - Bootcamp Santander & DIO

Este repositório contém o projeto desenvolvido como parte do Lab do Bootcamp Santander - Excel com IA e Claude, uma iniciativa promovida pela DIO (Digital Innovation One) em parceria com o Santander. O objetivo deste laboratório é explorar os recursos nativos da ferramenta de planilhas eletrônicas da Microsoft: o Excel para otimizar análises e o gerenciamento de dados.

## Sobre o Projeto

O projeto consiste em uma planilha estruturada para o acompanhamento e controle de Fundos de Investimento Imobiliário (FIIs). Através da aplicação de recursos avançados do Excel, a solução foi desenhada para facilitar a visualização de indicadores e a tomada de decisões de forma prática e automatizada.

## Recursos do Excel Utilizados

Para a construção e o funcionamento eficiente desta planilha, foram utilizados diversos recursos e funcionalidades nativas do Microsoft Excel, tais como:

Funções de Busca e Referência: Aplicação de fórmulas avançadas para cruzar informações e automatizar o preenchimento de campos com base em múltiplos critérios.

Formatação Condicional: Implementada para destacar visualmente variações, tendências e alertas importantes nos dados, melhorando a legibilidade.

Validação de Dados: Criação de listas suspensas e restrições de entrada para garantir a integridade e a padronização das informações inseridas.

Gráficos Dinâmicos: Representações visuais conectadas aos dados para facilitar o monitoramento do desempenho ao longo do tempo.
